\subsection{Step 9: Descriptive Profiling and Overlap Analysis}
\label{sec:step9}

Step~9 builds the descriptive atlas on the frozen graph family produced by Steps~7 and~8. Because the current data-driven selector may keep a thresholded sparse graph at one level and a full weighted graph at another, the atlas now carries level-specific graph-mode metadata in addition to level-specific representation and cutoff metadata.

The step contains four descriptive blocks:
\begin{itemize}
    \item graph profiles for every analytical unit;
    \item within-programme skill recurrence across years;
    \item programme-year progression overlap;
    \item cross-unit overlap relative to tracks, sections, programmes, programme-years, and the pooled universe.
\end{itemize}

The current implementation reads the final selected graph files from Step~7, not the retired sparse-only files. When a level has \texttt{selected\_graph\_mode = full\_weighted\_graph}, the atlas still reports graph sizes and node overlaps, but edge-overlap diagnostics are intentionally left blank because they are not substantively informative for complete weighted graphs.

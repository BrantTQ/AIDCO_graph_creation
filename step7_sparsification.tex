\subsection{Step 7: Automatic Data-driven Selection of Representation and Graph Cutoff}
\label{sec:step7}

Step~7 now follows the data-driven design in \texttt{data\_driven.tex}. The selection problem is no longer framed as a topology heuristic based on bootstrap edge Jaccard, susceptibility, or a pooled fallback rule. Instead, for each aggregation level separately, the workflow jointly selects:
\begin{itemize}
    \item the semantic representation; and
    \item the graph cutoff.
\end{itemize}

The aggregation levels are \texttt{pooled}, \texttt{track}, \texttt{section}, \texttt{programme}, and \texttt{programme\_year}. The candidate semantic representations are \texttt{name\_only} and \texttt{concat} (implemented from the Step~6 \texttt{name\_description} weights). Selection is performed on the frozen no-merge node universe inherited from Steps~4 and~5.

For each level and representation, the candidate threshold set is the set of distinct observed Step~6 edge weights at that level. The selection objective is the cross-validated skill score described in \texttt{data\_driven.tex}: holdout edge retention is compared against a holdout base-rate benchmark using log-loss, and the best representation-threshold pair is chosen separately for each level.

The practical implementation keeps the Step~6 edge weights fixed and resamples at the occurrence level through node-presence variation. Bootstrap edge-retention probabilities are computed analytically from train-fold occurrence counts rather than estimated by Monte Carlo simulation. This is exact for units in which each node is supported by a single occurrence and an approximation for the small subset of units with collapsed repeated occurrences.

If the best skill at a level is strictly greater than zero, the selected output for that level is a thresholded sparse graph. If the best skill does not exceed zero, the automatic decision is to retain the full weighted graph for that level. Step~7 therefore returns a final selected graph family, not only a sparse-only family.

\subsection{Step 2: Global Candidate Screening on Unique Textual Instances}
\label{sec:step2_global_similarity}

After Step~1 has produced a validated occurrence-level base, the next task is to screen for potentially equivalent skill labels at the global corpus level. This step is not a graph-construction step. Its purpose is to build a candidate table for later review and harmonization, not to choose the final sparse graph cutoff.

The corrected Step~2 uses \texttt{01\_unique\_textual\_instances\_vectors.csv} as its direct input. This file contains one row per unique textual instance rather than one row per unique skill name. The distinction matters methodologically: exact-name matches are no longer collapsed in advance, so the workflow does not hard-code the assumption that identical names must always correspond to the same harmonized skill. If exact-name duplicates exist, they are placed in a dedicated review stratum rather than treated as automatic matches.

For each unordered pair of textual instances, Step~2 computes cosine similarity under two fixed representations:
\begin{itemize}
    \item \texttt{name\_only}, using the normalized \texttt{name\_vector};
    \item \texttt{name\_description}, using the normalized concatenation of \texttt{name\_vector} and \texttt{description\_vector}.
\end{itemize}

The result is a global screening table that records both similarity values. A separate screening-cutoff file records the current provisional thresholds that define which pairs move forward to Step~3 review. Those thresholds are explicitly described as review-screening thresholds only. Final graph sparsification is deferred to Steps~7 and~8.

\subsubsection{Outputs of this Step}
\label{sec:step2_outputs}

The corrected Step~2 produces:
\begin{itemize}
    \item \texttt{02\_candidate\_pairwise\_similarity.csv}
    \item \texttt{02\_candidate\_screening\_summary.csv}
    \item \texttt{02\_screening\_cutoff\_selection.csv}
    \item \texttt{02\_exact\_name\_candidate\_stratum.csv}
    \item \texttt{02\_screening\_calibration\_template.csv}
\end{itemize}

The pairwise table is the main output. Each row represents one unordered pair of textual instances and includes the two similarity scores plus the identifiers and labels needed for downstream review. The exact-name stratum file is retained even if empty so that the handling of exact-name cases remains explicit.

\subsubsection{Fields to Fill After Concluding This Step}
\label{sec:step2_fields_to_fill}

The only file that may require analyst input at this stage is:
\begin{itemize}
    \item \texttt{02\_screening\_cutoff\_selection.csv}
\end{itemize}

In the corrected workflow, this file stores provisional screening thresholds and their status. The intended next improvement is pilot calibration on a labeled sample, because the methodological objective here is high review recall at manageable manual-review load, not direct graph optimization.

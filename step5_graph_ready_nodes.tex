\subsection{Step 5: Graph-Ready Node Construction Across Aggregation Levels}
\label{sec:step5_graph_ready_nodes}

Step~5 freezes the analytical units and constructs the graph-ready node tables on which all later weighted and sparse graphs are built. The corrected workflow makes every aggregation level explicit. The node universe is therefore defined for:
\begin{itemize}
    \item the pooled all-tracks unit;
    \item track units;
    \item section units;
    \item programme units;
    \item programme-year units.
\end{itemize}

Within each unit, all full-sample occurrence rows carrying the same \texttt{harmonized\_skill\_id} are collapsed into one graph node. The node embeddings are aggregated consistently across representations: normalized \texttt{name\_vector} values are averaged and renormalized to form \texttt{node\_name\_vector}, while normalized concatenated \texttt{name + description} vectors are averaged and renormalized to form \texttt{node\_name\_description\_vector}. This aggregation rule is held fixed across all later representation comparisons.

The node tables retain provenance counts and memberships so that downstream overlap and recurrence analyses can still be traced back to the underlying curricular structure.

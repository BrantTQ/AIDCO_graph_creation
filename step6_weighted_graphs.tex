\subsection{Step 6: Full Weighted Graph Construction}
\label{sec:step6_weighted_graphs}

Step~6 converts each Step~5 node table into a full weighted graph under both semantic representations. This step is mechanical but important: it freezes the common weighted candidate graph family from which later sparsification and selection are derived.

For every analytical unit, Step~6 computes cosine similarity between all unordered node pairs under:
\begin{itemize}
    \item \texttt{name\_only}, using \texttt{node\_name\_vector};
    \item \texttt{name\_description}, using \texttt{node\_name\_description\_vector}.
\end{itemize}

The corrected workflow now makes this graph family explicit for all five aggregation levels: pooled, track, section, programme, and programme-year. The weighted edges are stored in long format together with summary metadata so that later steps can reuse the same frozen weighted universe regardless of the eventual sparsification decision.
